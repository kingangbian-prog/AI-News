AI 公司与研究者

Dario Amodei / Anthropic：针对一篇说"其他 AI 公司领导人反对 Anthropic 让人类把自主权交给 AI"的报道，Amodei 发帖反驳，说他从没主张"把人类自由意志交给 AI"，这种说法很荒唐，他几百页文章里一直强调 AI 要受合法的民主程序治理。微软 AI 负责人 Mustafa Suleyman 随后公开站到他这边，说这场争论里口号和情绪太多，"口号不是护栏"，并推了微软写的《人本 AI 行为准则》，说这是把训练和部署护栏具体化的第一步。Anthropic 上市后股价刚跌破发行价，这时候被扣上"放弃人类自主"的帽子，Amodei 选择亲自下场。Amodei 原帖，Suleyman 回应

Anthropic：工程博客讲了 Messages API 从 Python 迁到 Rust 的过程，做法是让旧服务当参照，由几组 Claude Agent 对比新旧两版的输出差异、逐个定位修复。Replit 的 Amjad Masad 转发说，只要结果能验证，大规模软件迁移现在已经可行，这对跑在老系统上的关键基础设施很重要。用旧系统当测试基准、让 Agent 干对齐的活，这套方法别的团队可以直接借鉴。Anthropic 原帖，Masad

Pieter Levels（levelsio）：Claude 现在可以把 artifact 一键"安装为应用"，在 Mac 和 Windows 上像普通应用一样打开，能用连接器，用户允许的话还能发通知、加菜单栏图标。Levels 连发两条说"早告诉过你们它们会吃掉一切"，AI 公司会想接管操作系统，下一步可能是 iOS 和 Windows；他还设想 Anthropic 或 OpenAI 去卖预装 Linux 的便宜电脑，直接抢企业桌面市场。对做 PC OS 的人来说，模型厂商在桌面上直接生成和分发个人应用，已经从概念变成了产品功能。吃掉一切，接管 OS，卖电脑设想

Sam Altman / OpenAI：OpenAI 开始和一小批客户测试 Private Inference，归在 OpenAI Private Intelligence 产品线下。Altman 说更强的隐私保护能让前沿 AI 用在更多工作上，企业隐私对生态健康很重要。企业数据不敢上云一直是大模型进企业的主要障碍之一，OpenAI 在这块补产品。原帖

Greg Brockman / OpenAI：转发一位研究者的帖子，说 OpenAI 模型在 10 月给出矩阵乘法指数新上界 9/4 之后，又开始推下界，而这个方向此前几乎没有已知结果；Brockman 的引语是"我从没想过这辈子能看到这种结果"。他另外说 AI for science 的意义在于产生关于世界的新知识。这条如果后续经同行确认，会是 AI 做基础数学的一个硬案例，目前还停留在 OpenAI 方面的说法。原帖，AI for science

Mustafa Suleyman（微软 AI）：除了回应 Amodei，他还发了一句"我们正在越过一个门槛，安全和对齐是唯一重要的事"；又转发别人用 Opus 5.6 做的演示，评价"模型就是产品"，并说那些预测芯片建过头、看不到杰文斯悖论的人可以停了，"事情才刚开始"。微软的 AI 负责人公开夸 Anthropic 模型，值得留意。门槛，模型就是产品，芯片

Aravind Srinivas（Perplexity）：Gemini 4 Neon 周二在 Perplexity 内消耗 445 亿 token，离当天结束还有 3 小时就比周一全天高 23.5%，他说没见过哪个模型日环比涨这么快。晚些时候 Perplexity 上线 Time Machine，能让模型看到任意指定日期的网页原貌，用来后训练擅长预测未来的 Agent，已开放在 Search 和 Context API 里，之后还会做成按时间快照的沙箱供 rollout 和评测用。Neon 用量，Time Machine

Elon Musk：转发谷歌 Neon 首日 API 用量纪录，评价"谷歌干得漂亮"；转发 SpaceX 在亚利桑那 Cochise 县的超算基地 Colossus 3 的介绍，SpaceX 称投资 500 亿美元以上，不建燃气电厂、不用工业用水，采用干冷闭环，带来 1000 个长期岗位和最多 5500 个建筑岗位；还转发了一条引用黄仁勋的帖子，"你不会被 AI 抢走工作，会被用 AI 的人抢走"，回了一句 True。Musk 夸竞争对手谷歌不多见，Colossus 3 则说明 xAI 并入 SpaceX 后算力扩张还在继续。谷歌，Colossus 3，黄仁勋那句

Brett Adcock（Figure）：说"人形机器人是 AGI 的终极部署载体"，配的是访客参观 Figure 总部的视频，现场有 200 多台人形机器人在分拣包裹、做清洁。原帖

黄仁勋（英伟达）：复职后第一次开全员大会（美国时间 24 日，据《连线》看到的会议实录）。他为违反公司行为准则道歉，说"我伤害了你们所有人"，目前每天接受一个半小时心理治疗；称这是他主持过最艰难的公司会议，最难的谈话是和妻子那次。他否认复职是因为美国政府最高层要求，但英伟达 23 日的公告写明董事会听取了政府高级官员意见。管理上他承认过于强势会压制员工主动性，承诺每月做一次针对他本人的 360 度评估；接班问题上他说英伟达不需要传统接班人计划，他手下约 60 名直接汇报的高管各自能独立带队，董事会将来可以从中挑人。会上没有接受提问。英伟达的治理风波还没结束，参议院民主党领袖舒默已表示要调查。IT之家

车厂

何小鹏（小鹏）：25 日小鹏科技日演讲，说物理世界的难度被行业严重低估，举了谷歌 2012 年预测 2017 年普及 L4、马斯克 2013 年预测 2016 年实现 90% 自动驾驶里程这两个没兑现的例子，认为法规缺位、成本做不成商业闭环、网络时延带来的安全风险都会卡住物理 AI 落地，通用大模型只能解决一部分问题。会后媒体对话里他说机器人产业长期一定会超过汽车，短期要审慎，现在全球机器人市场可能只有几万台，买一台还要配很多人伺候的话 ROI 不成立；小鹏智驾在以过去 10 到 15 倍的速度自我进化；被问到特斯拉 FSD V15 时说自己没用过，"也许还处在比较科研的阶段"。小鹏首款 Robotaxi 定制车 YOYO-01 定在 2027 年发布。一边造人形机器人一边公开说物理世界被低估，这个口径比行业主流叙事冷静。物理世界，机器人，智驾与 FSD

李斌（蔚来）：25 日蔚来创新科技日发布世界模型 NWM 3.0 和 NOMI 4.0。李斌说汽车会是体量最大的 AI 应用产业，AI 有机会让汽车产业效率提升 15%，对应超过 1.2 万亿美元价值；光用 AI 工具不够，组织架构、业务流程、决策机制都要改，成为"AI 原生组织"是下一阶段竞争关键。蔚来内部已上线 7500 多个 Agent，累计运行实例超过 290 万。会后谈算力，他说现在主要租卡，因为需求有波峰波谷，卡又贵又买不到。7500 个 Agent 这个数字可以作为传统企业内部铺 Agent 的一个参照。观点网，新浪

李想（理想）：25 日晚 Q3 电话会上宣布，理想车型更新节奏从一年一次改为两年左右一次，2027 年只补一到两款独立车型，不做大面积改款。理由有三：符合工信部"两冬一夏"测试验证要求；产品周期长对保值率和服务更好；今年理想完成了自研三电和芯片上车，"不再被电池和芯片厂商的节奏带着走"。理想预计四季度盈利，人形机器人先在自家工厂落地，2027 年预计数百台规模，暂不做 C 端产品。在国内车企普遍一年一改款的竞争里，主动拉长周期是少见的选择。新浪汽车
