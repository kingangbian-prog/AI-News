AI大拿 最新言论追踪 · 2026-11-23

AI大拿每日言论摘要 2026-11-23（周一）　原文照录，仅整理排版。

范围：北京时间 11月22日早到 23日早。周五那期 7:46 交出，之后发生的个别重要内容也补在这里。

AI 公司与研究者

Sam Altman（OpenAI）：23日凌晨 1 点左右他转发首席科学家 Jakub Pachocki 的文章《Perplexity and Intelligence》，说这是 OpenAI 很久以来发布的最重要的东西，公司公开了预训练进展的内部数据，希望和同行在共同的限制上达成一致。按报道，文章第一次公布了 OpenAI 内部代码数据集上的 log-perplexity：GPT-3.5 约 0.99，GPT-4 约 0.91，降到 0.8 以下后模型开始出现网络安全和数学上的新能力，换到约 0.76 的模型后开始在数学开放问题上出成果。Pachocki 提议各家实验室用这类可横向比较的指标设一条线，在监控 AI 行为的能力跟上之前都不越线，还说最早 2027 年可能出现 AI 参与带来的一轮预训练突破。OpenAI 主动公开竞争敏感的数据来推行业界安全标准，这次比较少见。Altman 原帖，Pachocki 原帖，报道

Greg Brockman（OpenAI）：同一篇文章他也转了，说自己参与创办 OpenAI 就是为了让 AGI 安全，这篇文章公开的信息可以作为全行业共同安全标准的基础。原帖

Mustafa Suleyman（微软 AI）：他也公开支持 Pachocki 这篇文章。另外两条值得看：一条说模型能力每 3.6 个月翻一倍，但越来越难测，评测科学应该拿到前沿级别的投入，可能很快要立法要求；另一条提到一个 agent 收到「obtain shell access」一句指令，大约 11 分钟就找到并利用了一款医学影像软件的零日漏洞，他认为没有防护的 agent harness 是大的安全威胁，可能需要监管。支持 OpenAI，评测，agent 安全

Alexandr Wang（Meta）：23日早上他在 X 发长文《Superintelligence is Arriving》，从黎曼猜想被证明说起（上周 Anthropic 的数学家借助 AI 给出证明，独立数学家已确认），说这标志着重大转变开始了，人类接下来一年怎么做会影响很大。Meta 超级智能负责人这样公开定调，可以当作 Meta 后续动作的风向参考。原文，黎曼猜想证明的报道

Aravind Srinivas（Perplexity）：他说 Perplexity 是最好的不绑定模型的 agent harness，所有原语都在 code mode 里开放，能接最好的前沿模型。这是在拿 harness 层做差异化。原帖

Elon Musk

Tesla FSD V15 推送后他连发多条，说这是全新架构，开得比人好，配得上叫「超级」智能。有车主账号说 V15 比 V14 安全 25 倍，他转引时强调是 25 倍，不是 25%。这个倍数来自车主帖子，特斯拉没有公布对应数据。他还转了 Tesla 工程师的帖子，说 FSD、Robotaxi 和 Optimus 共用同一个世界模型，并顺带给 Tesla 芯片设计和 Terafab 招人。V15，25 倍，招人

手机厂商
