  4. Agent 购物和支付的标准开始落地
    X 新闻称 Sierra 发布开放协议 Poppy 1.0，Shopify 对全部商家默认开启，Wix 跟进，Meta Muse 已接入，100 多家合作方。OpenAI 11 月 13 日给美国 Pro 用户上线 ChatGPT Wallet，由 Dots 在对话里下单，生物识别确认，Visa、万事达、美国运通提供一次性令牌；Google 同日把 Google Wallet 只读接入 Gemini。 原帖

    X 新闻称 Anthropic 将以每股 70 到 78 美元在纳斯达克上市，代码 ANT，最多募 644 亿美元，高端完全摊薄估值约 1.4 万亿美元，约 11 月 19 日定价。产品侧放出 Claude Managed Agents 自托管私有 beta，并发布 always-on agents 架构文章，@shao__meng 的中文解读赞 1171、浏览 17.7 万。 原帖

  • ChatGPT Wallet / Gemini 接 Google Wallet
    前者让 Dots 在对话里下单，卡组织给一次性令牌；后者只读分析消费。AI 助手开始直接碰钱。 原帖
  • Devin Apps（Cognition）
    一句话让 Devin 生成私有内部网页工具（看板、项目状态页），跑在它的云电脑上，用时才唤醒，省成本。 原帖
  • Fish Agent（Fish Audio）
    无代码部署语音电话 Agent，中位 32 秒上线，用户拿它订位、问价、做客服。 原帖
  • Modern Web Guidance skill（Chrome 等）
    把 200 多条现代浏览器特性写法做成 Skill 给编程 Agent 查，避免生成老式 JS。@lxfater 认为别的领域也该有这类 Skill。 原帖
  • TokenEconomizer（微软开源）
    从 Agent 历史会话里学仓库事实、少加载用不到的工具，给 Claude Code 和 Codex 省 token。赞 879。 原帖
