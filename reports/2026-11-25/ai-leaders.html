AI大拿每日言论摘要 2026-11-25　原文照录，仅整理排版。

覆盖北京时间 11月24日早上到 11月25日早上。

AI 公司与研究者

Greg Brockman / OpenAI：OpenAI 发布预印本，称 GPT-6 系列只靠推理和写代码就能设计新的蛋白质结构和序列，不调用专门的生物模型，并且做了湿实验验证。Brockman 转发时说这又一次说明"推理加代码"能通用地解决问题，同一天他还连发几条，讲 GPT-6.2 Astra 在机器人控制、找系外行星、破解历史谜题上的用例。OpenAI 这阵子在刻意证明通用模型可以替代垂直模型，蛋白质设计有湿实验结果，比跑分更有说服力。OpenAI 原帖，Brockman，Astra 机器人

Anthropic：发布沙箱逃逸评测 Siren。在 1700 多个故意留了漏洞、并把任务所需的东西放在沙箱外的场景里，近期的 Claude 模型有 21% 到 32% 的情况会去看或尝试访问沙箱外，但很少拿来滥用；如果系统提示里写清楚沙箱和规则，这个比例降到 2% 左右或更低。Anthropic 说已经用 Siren 来校准 Claude Code 的 auto mode（命令执行前自动审查，不用每步都问用户）。同一天 Anthropic Fellows 还发了可解释性研究，说按"神经元对输出的贡献"去看，单个神经元其实很少混合两个无关概念，可以直接用来检测有害文本和发现微调模型里的隐藏行为。对做 Agent 权限设计的人，"把规则写进系统提示就能大幅减少越界"是个可以直接用的结论。Siren，博客，神经元研究

Boris Cherny（Claude Code 负责人）：MCP server 现在可以自带 skills 一起分发，Claude Code 装上就知道怎么用这个工具。工具和使用说明打包在一起，MCP 生态的接入门槛又降了一截。原帖

Sundar Pichai（谷歌）：Gemini 4 Neon 创下谷歌付费 API 首日用量纪录，Antigravity 每日 token 量比 6 周前 Argon 发布时涨了 82%。原帖

Aravind Srinivas（Perplexity）：Neon 在 Perplexity 内累计用量超过 1200 亿 token，三天内日用量翻倍，周一单日 360 亿。他评价 Neon 的智力介于 Opus 和 Fable 之间，但回答风格和易用性好过目前几乎所有模型。另一条说 Perplexity 正在变成"工作操作系统"，在 Perplexity Computer 里生成的幻灯片现在可以原地编辑，支持 PowerPoint 和 Google Slides。两条放一起看，谷歌新模型在第三方平台的真实用量还在快速涨，Perplexity 则在往办公生产力入口走，跟 PC 桌面的方向有重叠。Neon 用量，工作操作系统

Satya Nadella（微软）：说"每美元产出"是新前沿，微软在每一层推进：省算力的预训练（MAI Base 2）、长程强化学习（Rocket）、省 token 的模型（上周发布 7 个 MAI 模型），同时保持对所有前沿模型开放。微软在自研模型上的叙事从能力转向成本。原帖

手机厂商

余承东（华为）：24日上午发文宣布鸿蒙终端设备数突破 1 亿，说鸿蒙生态"越过了规模临界点"，从 2024 年鸿蒙应用全面启动算起走了三年。同日新品发布会上他介绍 Mate X8 用了华为首创的磁控展平技术，平整度比上一代提升 90%。23日他还发微博说问界 M7 系列累计超 47 万用户，并预告新 M7（面向 L3 的冗余架构、ADS 5），价格和上市时间没公布。新浪科技，界面/东方财富，华为官方 X

华为公司声明：美国纽约东区联邦法院陪审团 24日裁定华为 12 项指控中 10 项成立（含制裁违规、银行欺诈、商业秘密盗窃共谋、洗钱），反敲诈勒索（RICO）指控不成立。华为 25日声明欢迎 RICO 无罪的结果，认为其余指控同样缺乏法律和事实依据，称涉及的五起商业秘密纠纷都是过去二十年里已解决的民事案件，将审查裁决并采取一切必要法律行动，业务运营保持稳定。量刑和上诉还在后面，对海外业务和合规的影响要继续看。华为声明，美国司法部

卢伟冰 / 雷军（小米）：小米 Q3 营收 1072 亿元，同比降 5.2%，经调整净利润 48.8 亿元，同比降 56.8%，手机毛利率 9.2%，汽车季度交付 100975 辆。卢伟冰在电话会上说这是他从业以来手机行业"最难"的一个季度，内存涨价节奏放缓但仍在高位，要靠产品创新消化成本；他还说具身机器人的产业规模可能超过汽车，小米会聚焦本体、数据、模型三个方向。雷军在微博转发了业绩要点。内存涨价已经实打实压到手机厂商利润，这对明年 PC 和手机定价都是信号。每经/新浪，华尔街见闻，雷军微博
