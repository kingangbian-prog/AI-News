X 上热门的新点子 / 新 App / Skill / AI 助手

  • Antigravity /swarm
    一个提示词拉起一组分工 Agent，并行干活、互相检查，进度在共享看板上实时显示，可给不同角色混用模型。目前对 Google AI Ultra 订阅用户预览，耗 token 很快。 原帖
  • Inkbox：有电话号码的 Agent
    托管 Agent 自带电话、邮箱、iMessage、WhatsApp 和云电脑，用户用来协调房屋维修、订蛋糕、约牙医。刚拿到 Peak XV 领投的 530 万美元种子轮。 原帖
  • Teamily AI：群聊里的 Agent 同事
    Agent 像普通成员一样进群，读共享文件和聊天记录接活。7 月公开上线，一个季度注册从 1 万涨到 32 万，日活 2 万。 原帖
  • Paradigm：AI 原生大学
    Agent Clover 盯着你的交互画布主动给反馈，没有固定课表，按学习结果生成技能成绩单，已在 paradigm.study 开放。 原帖
  • Hypit 复刻爆款视频和广告
    开源工具，丢进别人的爆款短视频或广告，Agent 拆出剪辑、字幕、B-roll 流程，换上自己的产品批量出片。中文圈有人用 Claude Code 加 TikTok 数据接口批量测广告。 原帖
  • MAI-Transcribe-2
    微软的转写模型，每小时音频 0.10 美元。语音转写的价格还在往下走，ElevenLabs 同日发布 Scribe v3。 原帖

    商家在 Business Hub 认证后上传商品源和价格，发布 Business Agent 回答顾客；后台只看到汇总的提及和点击，看不到单个对话。Shopify 表态支持。这相当于 AI 助手里的商家黄页加客服。 原帖
  • OpenAI 收购旅行 Agent Odessia
    Odessia 一次对话规划并预订整趟行程，融资 600 万美元，用户规划的旅行年化 6,000 万美元。收购后原产品关闭，OTA 股价下跌，市场担心 Agent 直接下单绕开平台。 原帖
  • Vorflux 2.0：按目标和预算雇 AI 工程师
    AutoBots 常驻 Slack，主动修 Bug、审代码、跑测试，可从目录雇专用 Bot；内部数据称一个 Bot 合并 128 个 PR，人类 80 个。拿到 1,500 万美元种子轮。 原帖
  • TermiX：Agent 之间的托管和仲裁
    Agent 在链上建身份，雇其他 Agent 干活时先把钱放托管，交付靠哈希验证，有争议由 3 名随机评审投票。称已有每月数万美元的结算收入。 原帖
