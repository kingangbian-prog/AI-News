5 条核心结论

  1. OpenAI 发布 GPT-6.2 Astra 和 Sol，评价分化
    官宣帖赞 2.8 万、浏览 438 万，是关注时间线当天互动最高的 AI 帖。X 新闻称 Astra 在 Artificial Analysis 智能指数排第二，仅次于 Claude Fable 5.2；Perplexity 的 WANDR 测评里 Astra 0.783、每任务约 12.54 美元，Sol 0.746、约 2.65 美元。Theo、Matt Shumer 初测表示失望。 原帖
  2. Perplexity 把多模型编排做成产品和 API
    上线 Multiagent（主 Agent 把任务拆给用不同前沿模型的子 Agent）和 Orchestrator API（按能力、容量、延迟自动选模型，统一计费）。X 新闻称其年化收入已到 10 亿美元，8 月时超 7.5 亿，Srinivas 考虑最早 2027 年一季度 IPO。 原帖
  3. 编程 Agent 开始当常驻经理，软件工厂成融资热词
    Cognition 推出 Devin Bots：拥有目标、指挥编程 Agent、可连续跑几天到几周。X 新闻称一家游戏工作室每周 PR 从 50 涨到 1900，内测用户每条消息合并的 PR 平均多 4.5 倍。Islo Labs 融 1500 万美元做企业软件工厂，Lemonade 也在投资者日发布了自己的软件工厂。 原帖
  4. Agent 进入大众日常事务和支付，网站流量在流失
    Gemini Tasks 免费扩展到 6 个国家的数亿用户；ChatGPT 用户可连接 Coinbase 账户建组合、下单。Brian Armstrong 说屏蔽 Agent 很短视。另一边 X 新闻引 MarketWatch：Reddit CEO 称 10 月每周搜索引荐少了 100 多万次。 原帖
  5. 大额资金流向 AI 制药、机器人和算力金融
    Isomorphic Labs 获 50 亿美元 C 轮，20 多个项目推向临床，首批人体试验预计 2027 年。Genesis AI 获 5 亿美元 A 轮、估值 35 亿美元，做灵巧手机器人。Compute Desk 拿到 4500 万美元种子轮，要把 GPU 算力做成可交易、可对冲的资产。 原帖

新商业模式观察

是什么 · 为何火 · 商业角度

  • 多模型聚合商的收入验证
    Perplexity 年化收入 10 亿美元，年初不足 2.5 亿；Orchestrator API 接入 45 个以上模型。模型越多越分散，聚合和路由层越有议价空间。 原帖
  • Agent 支付和商家接入
    ChatGPT Wallet 让 Agent 代买，需生物识别确认；Coinbase 接入 ChatGPT。网站点击流量在降，接住 Agent 的商家可能拿到新需求。 原帖
  • 软件工厂卖给企业
    Islo Labs 1500 万美元（Insight 领投）：隔离环境、确定性管控、按历史工作做评测，与 Databricks 合作。卖点是可验证和安全，不只是写得快。 原帖
  • GPU 算力金融化
    Compute Desk 4500 万美元种子轮（Lightspeed 领投），在彭博终端发布每日算力价格指数，通过 Nodal Exchange 做期货。 原帖
  • AI 功能撑起超高价订阅
    Grindr 推出每月 120 美元的 Edge 档，AI 推荐和匹配分析，只面向约 1% 用户，用户吐槽不值。 原帖

    Meta 个人 Agent Muse 在澳洲上线并接入 Canva 等本地服务；同日澳洲团队发布 2200 亿参数、数据不出境的 Agentaus 1，融资不到 1000 万美元。 原帖
